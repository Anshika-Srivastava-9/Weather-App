# 🌤️ Weather App

A simple Python desktop weather application that fetches and displays **live weather information** for any city using the OpenWeatherMap API.

## ✨ Features

* 🔎 Search weather by city name
* 🌡️ Temperature
* 🌤️ Weather condition
* 💧 Humidity
* 💨 Wind speed
* 🌡️ Feels-like temperature
* 📍 Displays city and country
* ⚠️ Handles invalid city names and API/network errors
* ⌨️ Press Enter to search

## 🛠️ Technologies Used

* Python
* Tkinter
* Requests
* OpenWeatherMap API

## ⚙️ How It Works

1. User enters a city name.
2. The application sends a request to the OpenWeatherMap API.
3. The API returns weather data in JSON format.
4. Python extracts the required information.
5. Tkinter displays the weather details in the application.
